Let's start with Question 1. For each example, ask whether it is written as a set, and what its elements are.

The first item is just a list of numbers. In the notation we are using here, we write the set by putting curly brackets around them.

不会。重复书写不改变集合。这里有四个不同元素，通常每个只写一次。

A1 嵌套集合与空集

BOARD · 板书

SAY · 你说
How many elements does this set have? Try to identify the objects at the outermost level.
这个集合有几个元素？试着找最外层的对象。
动作 · 不读出

There are three elements: the number one, the set containing two and three, and the number four. The inner set counts as one object here.
有三个元素：数字 1、包含 2 和 3 的集合、数字 4。这里的小集合整体算一个对象。

A set can itself be an element of another set. We don't automatically unpack an inner set when we list the elements of the outer set.
集合本身也可以是另一个集合的元素。列出外层集合元素时，不会自动把里面的小集合拆开。

The empty set has no elements. The set on the right has one element, and that element happens to be the empty set. So these are different sets.
空集没有元素。右边的集合有一个元素，而这个元素恰好是空集。所以它们不相同。

The last examples also remind us that the objects in a set do not have to be numbers. A set can contain named objects, or even other sets.
最后几个例子也提醒我们：集合元素不必是数字，可以是命名的对象，也可以是其他集合。

记住这个区别：一个对象，和包含这个对象的集合，不能直接当成同一回事。第 3 题会用到。

A3 核心解释 属于和子集

09:18–09:23 · 这段务必出声练习一次

BOARD · 板书
{1,cat}∈Abut{1,cat}⊈A\{1,\mathrm{cat}\}\in A \qquad\text{but}\qquad \{1,\mathrm{cat}\}\nsubseteq A{1,cat}∈Abut{1,cat}⊈A
SAY · 你说
This is the key distinction. The set containing one and cat is an element of A, because that whole set is listed as one of A's elements.
关键区别在这里：包含 1 和 cat 的集合属于 A，因为整个小集合就是 A 列出的一个元素。
SAY · 你说
Being a subset is a different question. To be a subset of A, every element of the set on the left must itself belong to A.
成为 A 的子集是另一件事：左边集合里的每个元素，本身都必须属于 A。
动作 · 不读出
指向小集合内的 1，再指向 cat；一项一项检查，不要在口头说明中跳过 1。
SAY · 你说
So we have two checks: is one an element of A, and is cat an element of A? Cat is, but one is not. That means this set is not a subset of A.
所以我们要检查两件事：1 属于 A 吗？cat 属于 A 吗？cat 属于，但 1 不属于。因此这个集合不是 A 的子集。
SAY · 你说
One missing element is enough to show that a set is not a subset. We don't need every element to fail.
只要有一个元素不满足，就足以否定子集关系。不需要所有元素都不满足。
STUDENT · 学生可能问
But one is written inside A. Why doesn't it count?
可是 1 明明写在 A 里面，为什么不算？
BACKUP · 按需使用
It is written inside another set, which is one of A's elements. We are checking the elements at the outermost level, not everything that appears anywhere inside the notation.
它写在另一个集合内部，那个小集合才是 A 的一个元素。我们检查的是最外层元素，不是整段符号里出现过的所有东西。
BOARD · 板书
u∈A: check the whole objectB⊆A: check every element of Bu\in A:\ \text{check the whole object}\qquad B\subseteq A:\ \text{check every element of }Bu∈A: check the whole objectB⊆A: check every element of B
SAY · 你说
So the question to ask yourself is: am I checking the whole object, or checking its elements one by one?
所以你要问自己：现在是在检查整个对象，还是逐个检查它的元素？
教师备注
不要把 subset 讲成“元素更少的集合”，它可以与原集合相等。也不要说“左边是集合时只能用子集符号”。集合完全可以作为元素。

A3 剩余判断与简短理由

09:23–09:26 · 不必每小问再做一段长讲解

SAY · 你说
For statement d, we check cat and alpha separately. Both are elements of A, so the set containing cat and alpha is a subset of A.
d 要分别检查 cat 和 alpha。两者都是 A 的元素，因此包含它们的集合是 A 的子集。

为什么空集是子集？

To show that it was not a subset, we would need an element of the empty set that was missing from A. But the empty set has no elements, so there is no such counterexample.
要说明它不是子集，我们得在空集中找一个不属于 A 的元素。但空集没有任何元素，所以不可能找到这种反例。

Statement f is true because only the order has changed. Statement g is false because the elements have changed. For example, the set containing alpha is missing from the right-hand side.
f 为真，因为只改变了顺序。g 为假，因为元素改变了。例如，右边缺少包含 alpha 的那个集合。

A3 用新问题检查理解

09:26–09:28 · 快速检查 不必全部使用

BOARD · 板书
{α}∈A{α}⊆A\{\alpha\}\in A \qquad\qquad \{\alpha\}\subseteq A{α}∈A{α}⊆A
SAY · 你说
Before we move on, can these two statements both be true? Take a moment to think about the reason for each one.
继续之前，这两个判断能不能同时为真？想一下各自的理由。
动作 · 不读出
留 20–30 秒；先听一个人解释左边，再请另一人解释右边。
ANSWER · 回答参考
Yes, both are true. The whole set containing alpha is listed as an element of A. Also, its only element is alpha, and alpha belongs to A. So it is a subset as well.
可以，两者都真。整个只含 alpha 的集合是 A 列出的一个元素。同时，它唯一的元素 alpha 又属于 A，所以它也满足子集关系。
SAY · 你说
The same set can be an element and a subset of A. We just have to check each relationship separately.
同一个集合可以既是 A 的元素，又是 A 的子集。只要分别按各自定义检查。
动作 · 不读出
如果上述检查仍有人混淆，使用下面更小的例子；如果已理解，跳过，马上进入 Q4。
BOARD · 板书
S={1,{2}}S=\{1,\{2\}\}S={1,{2}}

Let's try a smaller example. What are the two elements of S? Is two itself an element of S? Is the set containing two an element of S?
用更小的例子再看一次。S 的两个元素是什么？2 本身属于 S 吗？只含 2 的集合属于 S 吗？
ANSWER · 回答参考
The elements are one and the set containing two. So two is not an element of S, but the set containing two is.
元素是 1 和只含 2 的集合。所以 2 本身不属于 S，但只含 2 的集合属于 S。
BACKUP · 按需使用
And the set containing two is not a subset of S, because its only element, two, is not an element of S.
而只含 2 的集合不是 S 的子集，因为它唯一的元素 2 并不属于 S。

A4 答案讨论与理由

09:33–09:40 · 让学生给结果 你补理由

SAY · 你说
Let's compare answers. What did you get for the union, and why?
我们对一下答案。并集是什么？为什么？
BOARD · 板书
A∪B={0,1,2,π,cat,dog}A\cup B=\{0,1,\sqrt2,\pi,\mathrm{cat},\mathrm{dog}\}A∪B={0,1,2​,π,cat,dog}
ANSWER · 回答参考
We include everything that appears in either set, and write each element only once. The elements that are in both sets still belong in the union.
把任一集合出现的元素都包括进来，每个只写一次。两个集合都有的元素仍然属于并集。
SAY · 你说
For the intersection, which elements appear in both lists?
交集呢？哪些元素在两个列表里都出现？
BOARD · 板书
A∩B={2,cat}A\cap B=\{\sqrt2,\mathrm{cat}\}A∩B={2​,cat}
ANSWER · 回答参考
The square root of two and cat are in both sets. The other elements appear in only one of the two sets.
根号 2 和 cat 两边都有。其余元素只出现在其中一边。
BOARD · 板书
A∖B={1,π},B∖A={0,dog}A\setminus B=\{1,\pi\},\qquad B\setminus A=\{0,\mathrm{dog}\}A∖B={1,π},B∖A={0,dog}
ANSWER · 回答参考
For A minus B, we remove the square root of two and cat from A, because they also belong to B. That leaves one and pi.
A 减 B，要从 A 中去掉根号 2 和 cat，因为它们也属于 B。剩下 1 和 pi。
ANSWER · 回答参考
For B minus A, we start with B instead. Removing the shared elements leaves zero and dog.
B 减 A 则从 B 出发。去掉共同元素，剩下 0 和 dog。
