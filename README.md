# Pure Week 1 teaching script

An English-first tablet teaching script with Chinese notes. This public site contains only the lesson script, not private email, original teacher PDFs or the full hand-in answer.

Open the site online once until the offline-ready status appears. Translation visibility, font size, selected section and timer are stored only on the device. No analytics or external runtime CDN requests.

KaTeX fonts and styles are bundled locally; its license is in vendor/katex/LICENSE.
