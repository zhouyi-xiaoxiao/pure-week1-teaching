# Pure Week 1 teaching materials

Public English-first teaching script and complete bilingual reference library. No account, password or access key is required. Publication of the complete reference was explicitly authorized by the owner.

The reference includes 39 topics with plain-language overviews, prerequisites, problem-solving strategies, complete questions and worked answers. Official results and independently supplied tutor explanations are labeled separately; B7 and Part C are not official published solutions. Original email records and teacher PDF files are not included.

Open each mode online once until its offline-ready status appears. Language, text size, selected topic and lesson timer are stored locally. No analytics or external runtime CDN requests. Old access keys are no longer needed and are not embedded in this public release.

The noindex metadata is a search-engine preference, not access control: anyone can open, copy or share this public material.

KaTeX fonts and styles are bundled locally; its license is in vendor/katex/LICENSE.
