# Pure Week 1 teaching materials

An English-first tablet teaching script with Chinese notes, plus an encrypted full reference library.

The public lesson script does not include private emails or original teacher PDFs. The complete reference library includes prerequisites, complete questions and worked answers. Only encrypted reference content is committed. A teacher access link is required to unlock it; possession of that link grants access. This is not a student handout, and not an account-authenticated portal.

Open each mode online once until its offline-ready status appears. Translation visibility, font size, selected section and timer are stored only on the device. The reference access key is remembered on the device after successful opening and can be removed with the clear-access button. No analytics or external runtime CDN requests.

KaTeX fonts and styles are bundled locally; its license is in vendor/katex/LICENSE.
